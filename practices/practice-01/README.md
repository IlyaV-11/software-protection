### Что объяснить на защите

- Коммит сохраняет состояние индекса. `git add` помещает выбранные изменения в индекс.
- При fast-forward указатель `main` просто перемещается вперёд; отдельный коммит слияния не создаётся.
- `--no-ff` создаёт коммит слияния даже тогда, когда возможно быстрое перемещение.
- Конфликт возникает, когда Git не может автоматически совместить изменения. Нужно исправить файл, выполнить `git add` и завершить слияние коммитом.
- `git push` отправляет коммиты на сервер; `git pull` получает изменения и интегрирует их в текущую ветку.
