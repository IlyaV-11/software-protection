## Готовый проект на этом Mac

Откройте папку `qa_demo` в VS Code. В терминале из этой папки:

```bash
source ../.venv/bin/activate
python -m pytest --cov=src --cov-branch --cov-report=term-missing --cov-report=html
PRE_COMMIT_HOME="$(pwd)/../.cache/pre-commit" python -m pre_commit run --all-files
```

Можно запустить файл «Проверить ПЗ5.command» в родительской папке.
Выберите интерпретатор Python из `Практическая 5/.venv/bin/python`.
Тесты используют TestClient; отдельный сервер для них не нужен.

## Установка в новом клоне

Из папки этой практической:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m pre_commit install
python -m pytest --cov=src --cov-branch --cov-report=term-missing --cov-report=html
python -m pre_commit run --all-files
```

Для точного набора зависимостей использованного запуска сохранён
`requirements-lock.txt` (Python 3.12.14, macOS ARM64).
FastAPI/Starlette в этой среде используют httpx2 в TestClient; пакет включён
в зависимости вместе с httpx из методички.

HTML-отчёт покрытия: `htmlcov/index.html`. При необходимости запустить API:

```bash
python -m uvicorn src.main:app --host 127.0.0.1 --port 8031
```

Открыть `http://127.0.0.1:8031/docs`. Приложение хранит данные только до перезапуска.

## Для защиты

- pytest проверяет поведение, например код 404 и удаление из справочника.
- TestClient вызывает ASGI-приложение внутри процесса без запуска HTTP-сервера.
- Black меняет формат, isort сортирует импорты, Flake8 сообщает о нарушениях.
- pre-commit запускает проверки до создания коммита. После автоисправления
  нужно заново добавить файл в индекс и повторить коммит.
- Параметризация запускает один тест с несколькими наборами данных.
- Фикстура не даёт тестам зависеть от оставленных друг другом товаров.
- Покрытие показывает выполненные строки и ветви, но не полноту требований.
- `python -m pytest tests/test_main.py::test_delete_item` — один тест;
  `python -m pytest -k delete` — группа по имени.
- CI может выполнять те же команды при push. Фактический запуск CI для ПЗ5
  не выполнялся: интеграция объяснена в контрольном вопросе отчёта.

Официальная документация: [pytest](https://docs.pytest.org/),
[pre-commit](https://pre-commit.com/), [Starlette TestClient](https://www.starlette.io/testclient/).
